# Obligatorio P2
Entrega final de Programación 2, realizada por un equipo de dos estudiantes, para la carrera de Analista en Tecnologías de la Información de la Universidad ORT, desarrollada en C# en .NET 8.0.  
Consiste en una web ficticia de e-commerce, en la que un usuario puede comprar y vender artículos, implementando también un sistema de subastas.  
Se enfoca en una profundización en el uso de clases, enfatizando algunos conteptos de SOLID como la Responsabilidad Única y el uso (inicial) de interfaces. Se implementó MVC para una separación rudimentaria de capas.  
El proyecto se orienta más hacia el Front-End, emulando una base de datos mediante el uso de una clase, y funciona como acercamiento al Back-End utilizando C#.
